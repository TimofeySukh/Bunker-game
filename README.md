# Bunker Game Telegram Bot

A simple Telegram bot that generates random bunker-game character traits. Now supports choosing language (English/Russian) at start.

## Prerequisites
- Python 3.8+
- Telegram bot token (from @BotFather)

## Setup
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=YOUR_TOKEN_HERE
python main.py
```

## Usage
- Open your bot in Telegram and send `/start`.
- Choose your language via the inline buttons.
- The bot will send generated characteristics.

## Notes
- Everything is localized (EN/RU).
